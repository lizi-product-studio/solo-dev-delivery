## 规则改在哪里

Skill入口增加短的“遇阻先恢复，必要时才交接”：先核实际错误、在授权内诊断并尝试有依据的恢复/等价入口，不凭一次失败或猜测要求用户处理；外部结果未知先对账，独立工作继续；确需身份、权限、业务决定或已证实无可行恢复路时及时最小交接。细节按需读`references/blocker-recovery.md`，不引入固定尝试次数、表格、角色或队列。

独立指令审查纠正一处可能被误读为“所有独立工作完成后才请求必要身份”的串行措辞，改为及时请求受限步骤、同时继续独立工作。它没有授予新增权限、收费服务、安全绕过或后台运行能力。[OpenAI官方指导](https://learn.chatgpt.com/docs/customization/overview)将AGENTS.md用于常驻工作约定、Skill用于按需工作方法；两层不能代替宿主实际工具与权限。

本机已在备份后同步简短全局AGENTS原则，以及既有安装中该Skill入口段和新引用；已核BUNDLE和Skill格式，21个既有其他文件逐字节保持，未整体升级其runtime或启用hooks/调度。当前会话随后实际收到更新后的AGENTS指令；未向其他聊天发送消息，不声称所有活动会话热加载。备份和本机路径留仓库外，不作为跨平台通用路径。其他Agent须实际更新/加载本Skill；宿主若有常驻指导，可采用同一短原则。
