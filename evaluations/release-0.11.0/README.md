# 0.11.0 统一验收候选

2026-10-23，分支 `release/v0.11.0` 基于 `3d79922`，包含之前各轮独立分支的累积成果；不合并 main，不创建 GitHub Release，不启用后台任务。目标是形成源码、分发包和本机安装一致的可用候选，并修复实际阻断，不以“最终极”宣称能力无限。

## 本轮实际改变

- Skill 入口明确适量执行方式和整项任务责任：完成计划、子任务或排障后继续原目标；已有有效控制优先复用。入口及引用统一为按实际需要选择门禁，已启用门禁继续生效。
- Windows 完整交付队列改为实际目录身份比较，支持本机 `.exe` 测试工具；不再因分隔符、大小写或原生解释器名拒绝合法任务，错误根目录仍拒绝。
- 原生审查 runner 超时使用已有自有进程树停止机制。未确认停止保留 UNKNOWN、active_run 和锁；恢复需结构化宿主扫描证据。正常完成不调用停止，不以超时接管正常 Agent。
- 日志和 Python 子进程明确 UTF-8，实际 cp936 父进程下中文、空格、emoji 仓库路径走完整交付链。
- 安装先暂存并核字节再发布，普通写入中断不留下最终目录半包；导出/安装成功 JSON 在 cp936+emoji 路径下不再误报失败。
- 收敛 README、安装说明和版本；CI 增加 Windows 完整交付/审查回归。首次七组测试通过、Linux包生成及安装核验通过，但上传触及Actions存储配额；改用仓库内版本化ZIP及校验值下载，全部测试成功后重建并逐字节核对，不自动发布稳定版本。
