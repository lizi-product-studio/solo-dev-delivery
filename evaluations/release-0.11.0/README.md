# 0.11.0 统一验收候选

2026-10-23，分支 `release/v0.11.0` 基于 `3d79922`，包含之前各轮独立分支的累积成果；不合并 main，不创建 GitHub Release，不启用后台任务。目标是形成源码、分发包和本机安装一致的可用候选，并修复实际阻断，不以“最终极”宣称能力无限。

## 本轮实际改变

- Skill 入口明确适量执行方式和整项任务责任：完成计划、子任务或排障后继续原目标；已有有效控制优先复用。入口及引用统一为按实际需要选择门禁，已启用门禁继续生效。
- Windows 完整交付队列改为实际目录身份比较，支持本机 `.exe` 测试工具；不再因分隔符、大小写或原生解释器名拒绝合法任务，错误根目录仍拒绝。
- 原生审查 runner 超时使用已有自有进程树停止机制。未确认停止保留 UNKNOWN、active_run 和锁；恢复需结构化宿主扫描证据。正常完成不调用停止，不以超时接管正常 Agent。
- 日志和 Python 子进程明确 UTF-8，实际 cp936 父进程下中文、空格、emoji 仓库路径走完整交付链。
- 安装先暂存并核字节再发布，普通写入中断不留下最终目录半包；导出/安装成功 JSON 在 cp936+emoji 路径下不再误报失败。
- 收敛 README、安装说明和版本；CI 增加 Windows 完整交付/审查回归，并在全部测试作业成功后导出、安装核验及上传候选 ZIP 和说明，不自动发布稳定版本。

两题首次 checker 均失败于**题目没有公开的结果字段格式限制**，不能写成业务首过或Skill故障：completed/结构化 verification 被拒，包含真实权限名的完整说明被要求精确等于枚举。原 checker、首次失败、原 manifest seal 均保留。仅修订未公开格式限制，复判显式携带原/新SHA绑定记录，结果中 revision_applied=true；未改业务、副作用、权限、源码抽查或候选。见 [缺陷与修订](behavior/fixture-defects-02.md) 和 [实际结果](behavior-results.json)。

作者控制23项全部符合预期，显式修订控制3项符合预期；这些是评测器自检，不是候选成绩。公开复现代码见 [行为评测说明](behavior/README.md)，不进入 Skill 分发包。首次结果、工具日志、原执行工作区与私有签名状态留本机；不导出原始会话。

这次没有旧/新同题对照，因此不声明相对收益。两题是本地仿真，不证明真实网站、账号、生产、恶意隔离、所有模型/宿主泛化或长期无人经营。最小交接产物和顺序有观察，实际用户通知时机未做独立量化。
