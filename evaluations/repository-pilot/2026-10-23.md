## 第1轮：有效验收在Windows默认编码下被读成过期

巡检发现：在Windows/Python3.12的默认cp936环境中，中文工作路径的`challenge freeze`与`run`均成功，紧接着`status`却返回`STALE`；全部文件不变，仅开启UTF-8模式则恢复PASS。另一巡检的已通过任务Stop误拦截指向相同控制JSON读写不对称，合并为一个问题，不另计一轮。

选择理由：有效证据被误判直接阻断交付、证据复用和结束回调；当前契约承诺证据未改变时可复用，影响优先于新功能和文案整理。范围为便携控制协议的UTF-8读写一致性，不改业务文件编码约定、失败优先、来源覆盖或原工作区防护。Windows超时清理异常是另一根因，保留为下一轮待核候选。

结果：统一`challenge/gate/coverage/sensitivity`的控制读写，hook显式读取UTF-8字节并输出ASCII转义JSON。实施时发现同一根因还会让既选风险记录漏读，以及中文session管道匹配失败，按必要调用链纳入本轮；未扩大业务语义或修改超时逻辑。

验证：新增协议回归先失败后修复通过；默认Windows cp936/PYTHONUTF8=0运行6项，无跳过，覆盖真实FAIL优先、过期阻断、新旧gate、实际管道hook和登记删除。原始freeze/run/status复现现均退出0，独立复跑的原hook复现也返回`{}`。相关旧回归80项通过。主Agent全量`python -X utf8 -m unittest discover -s portable-agent-kit/tests -q`退出0，183项、26.927秒，其中3项仅实际cp936环境运行的分支因当前UTF-8启动而跳过；这些3项已在上面的实际cp936定向运行中通过。没有把跳过算成执行通过。

## 第2轮：Windows验收超时丢失回执并遗留测试进程

从首轮提交重新巡检：编码修复后的freeze/run/status正常，但sleep测试配置timeout=1仍退出2、没有回执，原因是Windows没有`os.killpg`且未结束进程占用临时目录。另一执行者独立复现相同异常链。本轮优先恢复原有“超时UNKNOWN并只结束此次测试”的契约，未修改Agent预算、项目锁或调度策略。

主Agent最初重放固定目录的旧复现脚本遇`FileExistsError`，这是复现器不支持重复目录，不是产品超时结果；随后使用每次新建目录的原始复现，在当前提交再次观察timeout退出2、无回执，保留两次尝试，不覆盖旧文件。

实施：Windows使用系统绝对路径`taskkill.exe /PID <本次PID> /T /F`，不调用shell或按镜像名结束进程；POSIX保留独立测试session与进程组。工具等待、leader回收及fallback分别有界，终止/回收/目录清理错误进入`process_cleanup`。正常PASS/FAIL不触发终止器，清理故障不能释放PASS，旧证据变化仍STALE。

验证：新增6项先红后绿。实际Windows超时父子进程均退出，并行无关Python保持运行；CLI退出1且UNKNOWN回执可读；注入平台清理和临时目录故障后仍有错误证据且不通过。独立执行者重跑6项通过（5.178秒），主Agent全量便携189项通过（31.435秒，UTF-8模式中同样3项native-locale条件跳过，实际cp936另6项通过）。POSIX进程参数本机单测覆盖，真实Linux/macOS结果以该分支CI为准；没有宣称覆盖主动逃逸或持续创建子进程的对抗情况。

用户澄清0、额外审批0、手工修复0。内部协调和新增的窄范围进程审查计入成本。第三轮只读巡检同时发现安装器生成的Windows回调命令在默认shell不可执行；最简cmd方案被复杂路径反例推翻，暂不提交未经验证的启动方式。

## 用量复现与解释范围

同目录`measure_usage.py`是本次试点的Codex原生日志计量辅助，不是Skill默认步骤，也不是所有Agent平台的统一用量API。它仅读取显式给定的本机JSONL，不导出消息；按线程/response去重`token_usage_record`，忽略重复累计的`token_count`。自动接续可能产生新的turn，普通时间窗统计不要只给初始turn过滤。

本机私有配置示意（路径须由操作者明确指定，不提交真实会话日志）：

```json
{"started_at":"2026-10-23T03:01:22.750Z","sources":[{"role":"root","path":"/absolute/own-session.jsonl"},{"role":"implementation","path":"/absolute/own-child-session.jsonl"}]}
```

```sh
python evaluations/repository-pilot/measure_usage.py --config /private/pilot-sources.json --cutoff 2026-10-23T03:24:56.564Z --output /private/pilot-costs.json
```

合成计量自检实际通过：重复response/工具调用不重复计数，自动接续仍计入，截止后记录排除，累计事件忽略，缓存/推理不重复相加。来源快照、最初漏计稿和纠正稿均保留在本机输出目录。最终入库的去敏用量快照见`2026-10-23-costs.json`；统计截止后的提交、CI等待、最终答复与尚未落盘记录不在该快照内，不宣称是完整最终账单。

本试点证明两项真实缺陷被修复，以及未达验收的候选会撤回；没有无Skill对照，主Agent也知道本仓库历史，不能推导普遍质量提升、成本优势、长期经营能力或跨宿主泛化。
