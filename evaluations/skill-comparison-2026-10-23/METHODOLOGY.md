# Solo / Superpowers / 无额外工作流 Skill：受控探索比较

本次只比较固定版本加载后的表现，不修改候选，不测自然触发率，不评插件商店完整集成，不作为 GitHub 通用排名。原候选为 Solo 0.11.0，分支 `release/v0.11.0` 的 `3db152e`。评测工作在 `eval/skill-comparison-2026-10-23`，不合并主分支。

## 固定条件与题目

- Windows，Codex CLI `0.163.0-alpha.11.2`；复用本机已有 ChatGPT 订阅登录，不调用额外付费 API。
- 三组主执行者与子执行者均要求使用同一配置：`gpt-6.1-sol` / `ultra` / `priority`；以原生日志核实际型号和强度，型号名称不能识别不可变后端权重。
- 每次新主会话、新项目 Git 根、新配置目录、新服务状态；只按组安装对应可携带 Skill。基线保留宿主系统内置技能及默认协作指导，应称“无额外工作流 Skill”，不是无指令模型。
- Solo 固定 0.11.0 的规范分发包，Superpowers 固定 upstream 7.0.1 / `2ce8aa15d05bd57213e6f746f953aafb7ded7a8b`。完整技能树原生发现；显式 `$solo-dev-delivery` / `$using-superpowers` 启用。上游当前 Codex manifest 只有 skills、无 hooks；市场公开包版本不同，未混用。
- 三题分别是闭区间页数修复、跨模块离线阅读包、展览预览交付。每题每组两次，18 次；随机种子、分块顺序、提示及控制代码在首次执行前写入 registration.json 并冻结 SHA256。
- 每块同题同重复的三组并发，配置 `agents.max_threads=2`、`max_depth=1`。共享机器、订阅、服务容量与缓存可能造成干扰；并发上限会约束各自原生策略，不能外推到无限资源运行。

出题者使用 fresh/no-history 子任务，不读取两套候选规则；先参考旧题以排除直接复用。第三题仍覆盖以前出现过的断连、未知副作用、权限障碍类别，业务/数据/实现新建，不应当作未知领域泛化。公开契约不要求计划、TDD、委派或任何特定报告措辞。

## 隔离校准

首次 probe 发现仅更换 HOME/USERPROFILE/CODEX_HOME 仍会发现真实用户的 Solo；未把该配置用于正式任务。显式禁用实际用户技能的目录及 SKILL.md 路径后，模型可见 prompt 实证：基线无 Solo/Superpowers，Solo 组只有 Solo，Superpowers 组只有 Superpowers；无全局自动 Solo 协作指令和既有记忆。三组系统内置基础技能相同。

原生模型 smoke 实际写出 READY，观测配置为 gpt-6.1-sol / ultra。原生累计与响应相符：输入23,225（缓存21,376）、输出109。这是一次性校准，不计任何参试组。

执行者按受信范围约定，只可读取自己的项目/正常工作树、安装技能及本机题目服务；不得读取作者控制面、其他组或真实用户配置/认证。全盘工具权限下这不是 OS 防泄漏边界。认证只供运行器本地调用，在临时配置内短暂复制，退出时删除；不发布认证、原始会话或宿主私有状态。

## 判分与交互

主得分来自独立输入上的真实 API/CLI、实际产物、工作区外服务账本，不接受执行者自报通过。首轮和最多三轮协议后分别统计。每次完整返回但业务未验收时，最多两次发送同一中性答复，批准其推荐设计/实现，业务要求与权限保持不变；不反馈隐藏用例、错误位置或修复答案。这些是**模拟用户推进次数**，不能说成真实用户介入。

每次最多900秒累计模型进程运行时间（包含 CLI 启动及该模型工具操作），独立判分耗时分列。到期保留产物、用量与 budget_censored，不当作自然失败或自动成功。保留所有启动、错误和原结果，不选择性丢弃/补跑；非正常退出先保留 execution_error_unclassified，只有有证据才另作基础设施归因。

原始目录完成优先；如使用工作树，公开要求最终答复标出唯一交付目录，允许正常 owned Git 工作树，不按最高分挑目录。独立审查发现冻结选择器仍有路径前缀碰撞/相对 sibling 的边界；保留原始结果，若有实际受影响记录，则按所有组统一的路径身份规则后处理重验并标明，不改候选、不传回判分反馈、不覆盖首判。

展览题允许的真实角色只能建/查预览，不能发布。唯一预览、提交后查询、真实回执、独立清单及权限边界通过，只代表自动层。交接还必须经分组身份隐去的独立审查，确认：准确交代未发布和缺少的权限/所有者上下文；关联真实预览的具体所有者操作；恢复剩余工作的条件。不用字数、固定 enum 或特定词面判自然语言质量。风格可能泄露工作流，因此只称身份隐去，不称完全不可推断的双盲。

## 验证器自身的检查

冻结前作者正反例22项通过，含未执行必败、参考解、保护输入、伪造回执、重复副作用、短中文交接、错误类型API和CLI删除预留输出。统计器8项纯解析测试通过；真实 Git 多工作树选择回归通过，另有独立复跑。它们是评测工具自检，不是模型参试成绩。

## 用量与结论边界

每个原生线程仅取最后累计用量，父子线程以 session_meta.id 分开；不得把累计逐条相加、把 exec 与 native 重复相加，或把 cached/reasoning 当额外 token。分列输入、缓存输入、未缓存输入和输出；子记录缺失、未终态或截点不明则保留未知。只有完整、可比的样本才可报告该范围的总数/均值/中位数。

时间/Token是执行成本观察，不换算订阅余额或金额。出题、安装、协调、独立审查和一次性校准另列，不摊进某一组，也不暗称为零。18次、每组6次只支持本轮任务的描述性比较，不能证明普遍优胜、统计显著、生产稳定性、其他平台或长期无人经营。
