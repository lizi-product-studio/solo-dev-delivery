# 0.11.0 三组 Skill 对照结果

**本轮质量打平。Solo 比 Superpowers 的执行负担低，但相对不加载额外工作流 Skill，没有证明成功率或求助行为改善，且 Token 用量增加。** 不据此称为顶级、最终版或普遍更优。

2026-10-23，在同一 Windows / Codex CLI、gpt-6.1-sol / ultra 配置下，完成三类新题、每组每题两次，共18次。三组全在首轮通过独立业务验收；六份必要发布交接经身份隐去审查全部通过。没有追加模拟用户答复、预算截断、执行错误或选择性补跑。三组共同保留宿主默认自主协作能力。

在这组任务里，Solo 相比 Superpowers 平均用时少约36%、未缓存输入少约30%、输出少约33%；相比无额外 Skill，平均用时多约1.6%、未缓存输入多约15%、输出多约18%。这些是描述性观察，样本不足以声称统计显著或普遍净收益。中位与均值不同，且重复运行出现单项名次交换，不能挑最有利的一次解释整体。

## 实际检查范围

- 页数修复：公开 API 与18组独立 CLI 输入，闭区间、重叠、相邻、重复及去重统计。
- 阅读包：跨模块依赖、稳定拓扑、UTF-8 字节与哈希；21组正常/错误图的实际 CLI 和批量 API，含 ValueError 与失败不覆盖旧输出。
- 展览交付：默认入口不可用、提交持久化后丢响应、实际后续查询、唯一预览、真实回执、独立无障碍清单和所有者权限边界；这是本机仿真，未真实发布。

## 来源与有效性

三组使用独立主会话、新Git根、新服务账本。最初仅换配置目录仍发现全局 Solo；正式运行前显式禁用真实用户技能，再用实际模型可见 prompt 校准。最终18个样本的技能目录、指定全局协作/记忆标记与实际型号/强度审计全部通过。冻结控制代码、候选字节和本机安装仍匹配；临时认证已清除。

冻结目录选择器的路径前缀/相对 sibling 边界在独立审查中保留；本次所有样本均从原根目录验收、没有其他工作树，不影响成绩，不用常规测试通过掩盖该潜在限制。盲审展示曾误遮本机HTTP URL，已保留原展示与原审查并统一修正；九项重审无改判。未改变候选、自动判分器或业务规则。辅助“是否提问”分类在审查员间有解释差异，不用于排名；主要的不必要阻塞求助判断一致。

真实文件系统隔离、所有越界读取、不可变后端权重、其他宿主/模型和长期真实项目均不在本轮证明范围。18次是3类任务的重复，不是18种独立项目。显式加载 Skill 的效果不能解释为自然触发率。

## 下一步的依据

当前题库存在明显的成功率上限，未复现用户真实工作中的过早移交。后续优先收集与脱敏实际失败，建立新的保留任务，检查规则能否减少同类错误且不增加不必要流程。用户最新指出的界面说明堆积与产品设计问题不在这18次里，将另开前端专项研究和候选验证；不把本轮代码题通过冒充审美或架构认证。
