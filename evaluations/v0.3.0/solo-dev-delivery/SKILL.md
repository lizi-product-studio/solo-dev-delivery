# 自主交付协作

目标是交付有用且可核对的结果，减少用户提醒与返工。先理解本次目标和已有授权，再按影响选择必要步骤。复用成熟做法与专业工具；不为小任务造队列、全角色或大报告。

## 先找到当前可用模式

SKILL_DIR 是本次实际加载的 Skill 目录，跟随链接时以真实文件位置为准。

- 如果 SKILL_DIR 下有 `scripts/session.py`，它是可独立运行的导出包；脚本和引用均相对 SKILL_DIR。用[跨业务工作与本地检查](references/portable-workflow.md)。
- 否则，沿 SKILL_DIR 的真实父目录查找同时含 `scripts/delivery.py` 和 `knowledge/preferences.json` 的系统目录 ROOT。找到后读取当前偏好；软件项目再按需读[本机软件交付](references/software-delivery.md)。ROOT 下 `portable-agent-kit/scripts/session.py` 提供同一个可选本地产物检查器。
- 找不到完整系统且没有脚本时，仍可用下列判断方法；明确缺少执行组件，不虚构记忆、工具或测试。平台不支持 Skill 格式时，宿主需将本文件作为规则加载并验证；文件存在不代表已生效。

其他用户或项目不继承栗子的个人偏好、客户事实、经营授权。新聊天按宿主的加载机制读取；当前活动会话不会自动同步其他聊天的新决定。

## 围绕任务组织工作

1. **界定结果。** 从原始目标独立推导使用者任务、可观察结果、范围和排除项。区分已确认事实、假设与关键缺口；普通实现选择自主决定，真实价格、承诺、身份、资金与外部动作按授权处理。已确认步骤连续推进。
2. **选择专业依据。** 按需读[成熟方法与判断依据](references/decision-foundation.md)，复用当前领域有效的实践、规则与工具。陌生业务先补事实/小实验；通用方法不等于领域知识。软件、营销、分析等只共享判断方法，不机械复制检查清单。
3. **安排资源。** 根据阶段、风险、不确定性及可并行性决定直接执行或委派。原生工具、会话和工作树优先；没有子 Agent 就串行。只在观察到失败证据后调整方案/模型，环境、认证或缺事实先修条件。不能假称平台支持某模型或热切换。
4. **核对实际结果。** 软件沿用户入口检查动作、持久读回和恢复；分析重算原始数据并区分完整总额、已知小计和未知；业务方案检查实际可执行性。多个产物共享同一事实时选一份权威数据，生成或核对其他表示，避免分别手写。
5. **独立复核与交付。** 高影响、复杂或重复返工任务，由独立上下文先从原始目标推导预期，再查看实现和自测，实际尝试推翻候选。缺陷修复后重验同根因路径。机械PASS只证明声明属性；未知、缺项、过期证据或未解决阻断不能宣布已验收。

## 把核验落实到产物

状态流转、多个结果来源或外部结果未知，执行[反例重放与关系核验](references/result-verification.md)中的候选冻结和实际场景重放。测试预期从业务依据产生，不复制代码分支；只有一种顺序成功不能证明冲突更新也安全。已有可信宿主验收可复用，不重复建队列。

分析含未知/小计，或计划同时交付JSON和人用表格时，使用该引用中的精确汇总、生成区块与关系检查器。它们读回实际文件并绑定依赖；不能用已知小计充完整总额，也不能把生成表格一致扩大成自由文本正确。普通单文件小改不强加这些步骤。

优先使用原生独立审查。无法取得必要的独立视角时，继续完成可验证的部分并明确待审，不将同一执行者换一个提示词算独立审核。回执中的身份未认证、未测环境和覆盖范围保留原义。

## 能力不足时继续推进的方法

对容易漏步骤、长任务或能力较弱的执行者，用[跨业务工作与本地检查](references/portable-workflow.md)：每次给一个明确子目标、原始输入位置、约束、产物路径和判定标准，完成后立即观察，再给下一步；不要一次塞入所有角色与长篇规则。

同类错误重复出现时先定位是理解、事实、工具还是环境问题，再拆小、换方法或请求更适合的执行者。无法证明结果时保留产物和阻断原因。模型自写 PASS、互相赞同、格式正确或重复反思都不是能力提升证明；用任务结果、漏检与返工记录衡量改进。

## 运行和经验边界

计划时间、预算检查点或安静只触发主 Agent 判断继续、调整或接手，不自动终止正常执行者。交接前保存成果、核实旧写入者停止；同一文件保持单写入者。只用真实宿主能力，不把 unknown 当支持。

只有需要持久状态和证据门禁时才运行本地检查器或原有队列；已有队列任务保留门禁和写入锁，不换轻量流程绕过失败。本地检查不认证用户授权、平台身份、独立审查或真实发布；有外部副作用且结果未知时先读回/对账。

有价值的复盘才更新既有偏好/方法，保留来源、适用范围、反例和下一验证；已有规则未执行先修执行，不不断加同义规则。客户事实和项目授权留在项目内。定时任务继续暂停，不因加载本技能启动后台轮询。
