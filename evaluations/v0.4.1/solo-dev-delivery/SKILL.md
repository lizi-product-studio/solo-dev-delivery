# 自主交付协作

以项目实际结果、漏检和返工评价工作。先确认本次目标和有效授权，复用适合当前领域的成熟方法；不把用户提醒作为必要验收的启动条件。

## 先选本次最小路径

- **局部小改**：只改变一个局部可观察结果，且不改变业务状态、权限或约束时，直接实施并定向读回；复用有效检查，不建覆盖表、队列或多角色。
- **有业务约束的交付**：影响持久状态、权限、相互制约的政策或多份执行资料时，主Agent先从原始目标推导关键结果和最可能推翻它的条件，再实施。本地计算/Python用下述brief→freeze→assess一次性入口选择并执行检查，不另写一套无关联的自检来代替。已有当前可归属回执直接复用。
- **真实界面/外部环境**：App、小程序、网站、Agent工具或外部服务，按同一结果选择原则调用宿主的真机/浏览器/集成工具；不伪造Python回执。缺少必要环境时交付已验证部分并保留缺口。

复杂度看业务结果与影响，不看文件/代码行数。普通实现选择自主推进；需求有歧义先完成不依赖它的工作，再补事实，不编造经营政策。

## 工具在哪里

实际加载目录为SKILL_DIR。若其下有scripts/challenge.py，S=SKILL_DIR/scripts，所有引用相对本包，不读取别人的个人偏好。否则沿真实父目录找到同时含scripts/delivery.py和knowledge/preferences.json的ROOT，读取当前偏好，S=ROOT/portable-agent-kit/scripts；软件细节按需读[本机软件交付](references/software-delivery.md)。找不到时说明缺少工具，不虚构记忆或运行结果。

## 主Agent的结果核验入口

原始目标/政策在文件中时，先执行下面入口；若只在聊天中，按本次范围保存必要原话作为依据，不把推断当确认。控制文件放候选工作区外。详细参数和小例在[场景选择与结果核验](references/result-verification.md)。

```sh
python3 S/challenge.py brief --workspace CANDIDATE --input GOAL.md --brief REVIEW/basis.json
```

主Agent按brief的原文段落写一份小plan：关键可观察结果、来源、优先级、对应Class.test_method和相对检查成本；同段可能含多个条件，不能只核其中一句。场景只选能排除具体风险的正常/边界/冲突/失败恢复/无解视角，不套全套清单。检查预期从原目标产生，不能照抄实现分支。用既有freeze绑定原始依赖与候选，然后：

```sh
python3 S/challenge.py assess --brief REVIEW/basis.json --plan REVIEW/plan.json --packet REVIEW/candidate.json --run --report REVIEW/coverage-1.json
```

工具优先补未覆盖结果，合并同一方法覆盖的结果，读回本次控制目录已有证据而不重复运行。来源漏登、未实际执行、UNKNOWN/STALE、预算不足或未解决失败均保留缺口；失败后先定位原因并核对共享业务依据的相关结果，不机械全量重跑。同候选/脚本的已知失败不能通过漏带回执或从plan删掉方法抹掉。

DECLARED_SCOPE_COVERED后，主Agent仍须对照原文检查：context排除是否合理、同段还有没有重要条件、实际断言能否识别错误、人用说明是否与执行结果一致、未测环境是否影响交付。必要独立审查按影响使用已有原生能力；换提示词自审不算独立。局部PASS不能扩大成完整验收。

未知合计/已知小计与JSON/人用表格，用同引用中的精确关系核验；自由文本不由关系PASS证明。专业依据按需读[成熟方法](references/decision-foundation.md)，能力不足时用[分步执行](references/portable-workflow.md)。

## 资源与权限

默认主Agent直接推进；只有可并行的独立工作或确有必要的独立视角才委派。依据实际失败、环境和事实缺口调整方法/模型，不堆Agent。时间、安静或预算检查点只触发继续/调整/接手判断，不停止正常执行者；接手前保存成果并确认旧写入者停止。

普通任务不初始化持久session。完整系统仅在跨进程恢复/交接且宿主记录不足时使用既有队列；已有任务继续原门禁、失败记录和写入锁。脚本不认证授权、独立身份、完整语义或生产发布；有外部副作用且结果未知时先读回/对账。

上线、资金、外部通信、费用、身份及承诺遵守本次明确授权，历史项目授权不迁移。定时任务保持暂停。经验只在有验证价值时更新原记录，保留来源与适用范围；当前活动聊天不自动同步别的聊天新决定，跨平台真实加载需宿主验证。
