# Cursor 接入

优先按[通用安装](../generic/README.md)使用自包含agi-like包，在当前Cursor版本的文档/配置中确认Skill目录或规则入口。不要将完整个人系统作为默认插件安装。

如果使用项目规则，可人工选择本目录AGENTS.md片段或agi-like.mdc模板，合并进已有规则并提供实际Skill路径；不要覆盖项目已有授权和约束。模板按需加载，不要求每个动作经过AAP。只有明确需要持久恢复时才接入完整系统协议。

安装后验证菜单发现/实际规则加载、临时项目的小改读回和失败修复。文件复制与本地包测试不代表Cursor实机加载、自动分流或浏览器能力已通过。
