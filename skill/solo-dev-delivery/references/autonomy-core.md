# 自主交付核心循环

这是本 Skill 的唯一总框架。它只在任务有明确产物、需要多步推进、会改变行为/数据/界面，或用户要求 Agent 自己发现问题和持续改进时启用；简单问答和可回退的一步小改直接处理。

## 先形成一份当前状态

从原始请求、有效授权、当前产物和宿主能力提取：

`goal` 原始目标与验收结果、`scope` 可改范围与排除项、`impact` 业务后果/外部副作用、`uncertainty` 未知事实、`capabilities` 当前可用工具/环境、`evidence` 已有且仍有效的观察、`ownership` 当前写入者与未对账的外部操作。

没有来源的业务政策、权限或生产事实保留为 `unknown`，不由模型补全。旧消息、旧授权、旧 PASS 和局部成功不能自动扩大当前范围。

## 用四个决定驱动任务

| 决定 | 输出 | 选择依据 |
| --- | --- | --- |
| 分流 | `QUICK`、`BOUNDED`、`GOVERNED`、`MAINTENANCE` | 影响、不确定性、回退难度、外部副作用和是否需要跨会话接续 |
| 边界 | `AUTO`、`ASK`、`STOP`、`DEFER` | `AUTO` 只用于已授权且可安全读回；`ASK` 只问业务决定/身份权限；`STOP` 保留未知或高风险结果；`DEFER` 记录能力缺口并继续可做部分 |
| 证据 | `DONE`、`NEEDS_EVIDENCE`、`BLOCKED`、`BUSINESS_DECISION` | 是否观察到原始目标的实际结果、持久读回/界面状态、当前版本绑定和必要条件 |
| 下一步 | `CONTINUE`、`REPAIR`、`REPLAN`、`HANDOFF`、`CLOSE` | 当前观察与原目标的差异；不能因为完成一个计划、子任务或工具调用就结束 |

任务影响由事实决定，不由文件数、项目名称、模型名称或“加载了 Skill”决定。没有真实宿主能力时，能力状态保持 `unknown`；`unknown` 不能当作支持、成功或授权。

## 执行、恢复和验收

1. 为当前目标选最小可观察动作，写清会改变结论的条件和预期结果；复用已有有效检查。
2. 真实执行并读回结果。遇到阻塞先区分可恢复技术故障、业务决定、身份/权限边界和未知状态；可安全恢复的由 Agent 诊断、修复、重走原动作，受阻期间继续独立工作。
3. 用户只需要决定未定义的业务政策、本人身份/权限、凭据授权或不可逆外部动作。交接必须带观察事实、已完成部分、精确阻塞、用户最小动作和恢复条件。
4. 外部写入结果未知时按原操作身份对账，不盲目重复；意图、对象、版本或条件改变时使旧待办和确认失效。
5. 只有原始目标在适用的真实入口得到观察，持久结果/回读与可见状态一致，当前证据仍绑定且没有影响交付的失败或必要未知时才 `CLOSE`。局部 CLI、模型自评、截图存在、构建通过或模拟器成功只证明各自范围。

失败优先于成功，未知优先于未测的乐观推断；候选、原文、适配器、检查或版本变化会使旧证据失效。简单任务不因为这套循环强制计划、工作树、子 Agent、独立审查或持久队列。

## 从结果生成下一轮计划

用户反馈、真实失败、未完成里程碑和交付后观察先去重并绑定来源，再按用户损失、既定目标阻断、解除依赖的价值、证据成本和可回退性排序。选择一个当前授权内且能改变决定的最小动作，写下预期观察、停止条件和恢复条件；完成后比较实际结果，保留有效方法，修正或撤回无效规则。没有合格待办、预算或外部依赖时结束本轮并说明再次启动条件，不无限循环。

## 引用路由

- 排障和风险分流不清：读[工程方法](engineering-practice.md)；实际阻塞和最小交接：读[恢复与最小交接](blocker-recovery.md)。
- 用户要求自己找问题、出现同类返工或主要界面/多轮行为变化：读[交付前主动自审](delivery-self-review.md)；新界面再读[产品界面与前端设计](frontend-quality.md)。
- 需要正式候选绑定、决策模型或隔离反例：读[交付门禁](execution-gate.md)和[结果核验](result-verification.md)，不重复建立另一套门禁。
- 需要跨任务、版本或宿主比较：读[评测合同](evaluation-contract.md)，使用 `scripts/eval_contract.py` 校验/汇总，不把描述性统计当成业务验收。
- 用户授权的项目巡检和持续改进：读[项目巡检与自主改进](project-operation.md)。跨宿主安装和能力探测：读[宿主安装与预检](host-integration.md)。完整本机队列：读[本机软件交付](software-delivery.md)；轻量跨业务检查：读[跨业务工作](portable-workflow.md)。
